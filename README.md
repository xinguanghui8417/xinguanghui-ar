# xinguanghui-ar（新广汇 AR 技术层 · 公开仓库）

> 这是「广汇报价」App 的**公开技术仓库**——只放纯 AR 技术代码（M1~M3：平面检测、场景扫描建模、区域修饰锚定、3D 预览）。
> 所有**机密逻辑**（算料引擎、计价规则、价格库、客户数据）在私有仓库 `xinguanghui-core`，**永不进入本仓库**。

## 项目一句话

广告展示工程现场：扫描场景 → 3D 空间模型 → 圈选锚定 → 选施工内容/尺寸/材料/工艺 → 自动算料 → 自动报价（iOS 原生，ARKit）。

## 技术栈

- Swift + SwiftUI（或 UIKit）
- ARKit + SceneKit（或 RealityKit）
- iOS 15.0+，真机 iPhone 13 Pro（LiDAR）

## 里程碑（对应开发任务书）

| 里程碑 | 内容 | 状态 |
|---|---|---|
| M1 | AR 基础：平面检测 + 识别指示 + 墙面朝向 | 待开发 |
| M2 | 场景扫描建模 + 区域修饰 v1（点选吸附矩形 + 锚定） | 待开发 |

## 构建

本仓库通过 GitHub Actions 在云端 macOS 上自动构建（公开仓库构建免费不计分钟）。
